# 🚀 Astronaut's Space Hunt

My first Scratch game, created for Harvard's CS50X Problem Set 0.

## 🎮 About the Game

Control an astronaut, collect stars, and avoid asteroids in this space-themed game.

## ✨ Features

* Astronaut movement and jumping
* Star collection and scoring
* Asteroid collision detection
* Win and game-over screens
* Background music and sound effects
* Play again and return to menu options

## 🛠️ Built With

* Scratch

## 📚 What I Learned

* Conditions and loops
* Variables and scoring
* Collision detection
* Game logic and interactive design

## ▶️ How to Play

Download the `.sb3` file and open it in the [Scratch editor](https://scratch.mit.edu/projects/editor/).
